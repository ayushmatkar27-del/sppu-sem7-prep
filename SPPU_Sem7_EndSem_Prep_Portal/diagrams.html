📖 Pozar Ch. 3 • Microwave Engineering

Rectangular Waveguide TE10 Mode Field Pattern (Unit 3)

6 Marks • End-Sem / Unit 3

For dominant $\text{TE}_{10}$ mode in rectangular waveguide ($a > b$), the electric field $E_y = E_0 \sin(\pi x/a)$ is purely vertical and varies sinusoidally across broad wall width $a$ (maximum at center $x = a/2$, zero at conducting sidewalls $x=0, a$). Magnetic field lines form closed horizontal loops in the $x-z$ plane.

✏️ 30-Second Exam Blackboard Draft:
Draw a rectangle ($a \times b$). Draw 5 vertical arrows pointing UP: tallest in center, shorter towards sides, zero at left and right edges. Write: λ_c = 2a, fc = c / 2a, Ey ∝ sin(πx/a).
📖 Pozar Ch. 7 • Microwave Engineering

Magic Tee (Hybrid 4-Port Junction)

6 Marks • Q1/Q2

Combines an E-plane and H-plane tee. Symmetric input at Port 3 splits in-phase into Port 1 & 2. Anti-symmetric input at Port 4 splits 180° out-of-phase into Port 1 & 2. Port 3 and 4 are completely isolated ($S_{34}=S_{43}=0$).

✏️ 30-Second Exam Blackboard Draft:
Draw 1 horizontal bar (Ports 1 & 2) + 1 vertical upward arm (Port 3, H-plane Sum) + 1 downward arm (Port 4, E-plane Diff). Write: [S] = 1/√2 * [ 0 0 1 1 ; 0 0 1 -1 ; 1 1 0 0 ; 1 -1 0 0 ].
📖 Liao Ch. 9 • Microwave Devices & Circuits

Reflex Klystron & Applegate Diagram

6/8 Marks • Q1/Q2

Applegate space-time diagram illustrates velocity modulation. Early electrons accelerate, travel deep into the repeller space, and return later; late electrons decelerate, take a shallow turn, and converge together to form dense electron bunches at the cavity during the retarding phase.

✏️ 30-Second Exam Blackboard Draft:
Draw z vs t axes. Draw 3 parabolic curves meeting at 1 focal bunching point on the cavity line. Write: Transit time T0 = (n + 3/4)T | Max efficiency = 58.4%.
📖 Liao Ch. 9 • Microwave Electron Tubes

Cavity Magnetron (8-Cavity π-Mode Spokes)

6 Marks • Q1/Q2

Crossed-field tube where radial DC electric field is perpendicular to axial magnetic field. Electrons emitted from the central cathode swirl into 4 rotating spoke clouds under $\pi$-mode oscillation (adjacent cavities 180° out-of-phase), transferring kinetic energy to cavity RF fields.

✏️ 30-Second Exam Blackboard Draft:
Draw concentric circles (small cathode, large anode). Draw 8 mini-holes on perimeter. Sketch 4 pinwheel arms between cathode and cavities. Label: E radial, B axial, π-mode Phase shift = 180°.
📖 Weste & Harris Ch. 12 • CMOS VLSI Design

6T SRAM Cell (Hold, Read & Write)

6/8 Marks • Q3/Q4

Standard 6-transistor SRAM cell consists of 2 pull-up PMOS (PU1, PU2), 2 pull-down NMOS (PD1, PD2) creating cross-coupled bistable latch, and 2 NMOS pass-gate access transistors (PG1, PG2) activated by Word Line (WL).

✏️ 30-Second Exam Blackboard Draft:
Draw 2 CMOS inverters facing each other with cross-wires connecting input to opposite output. Connect Left to BL via NMOS, Right to BLB via NMOS. Label gates: WL. Sizing: Cell Ratio (PD/PG) > 1.2 | Pull-up Ratio (PU/PG) < 1.0.
📖 Weste & Harris Ch. 9 • CMOS VLSI Design

Dynamic Domino CMOS Logic Stage

6 Marks • Q4

Composed of a dynamic CMOS stage followed by a static CMOS inverter. During Precharge ($\text{CLK}=0$), $M_p$ pulls dynamic node high, so $V_{\text{out}}=0$. During Evaluate ($\text{CLK}=1$), footer $M_e$ enables discharge only if logic evaluates true, ensuring cascading stages never falsely discharge.

✏️ 30-Second Exam Blackboard Draft:
Draw vertical column: PMOS (CLK) $\to$ Logic Box $\to$ NMOS Footer (CLK). Draw wire from intermediate node into a standard inverter triangle. Label: Precharge: CLK=0, Vdyn=VDD, Vout=0 | Eval: CLK=1.
📖 Goodfellow Ch. 10 • Deep Learning (MIT)

LSTM Cell: 3 Gates & Cell State Highway

6/8 Marks • Q7/Q8

The Long Short-Term Memory cell resolves vanishing gradients with an additive Constant Error Carousel (cell state $C_t$). Information flow is modulated by 3 sigmoid ($\sigma$) gates: Forget Gate ($f_t$), Input Gate ($i_t$), and Output Gate ($o_t$).

✏️ 30-Second Exam Blackboard Draft:
Draw 1 horizontal top line ($C_{t-1} \to C_t$). Place a ($\times$) circle, then a ($+$) circle. Below draw 3 boxes labeled $\sigma$ (Forget), $\sigma$ (Input), $\sigma$ (Output). Write: Ct = ft·C_{t-1} + it·C̃t | ht = ot·tanh(Ct).
📖 MDN Web Docs • Runtime Architecture

JavaScript Event Loop & Concurrency Model

6 Marks • Q5/Q6

JavaScript executes synchronous code on single-threaded Call Stack. Asynchronous tasks offload to Web APIs. Upon completion, Promise callbacks land in the high-priority Microtask Queue, while timers land in the Macrotask Queue. The Event Loop prioritizes Microtasks before touching Macrotasks.

✏️ 30-Second Exam Blackboard Draft:
Draw 1 vertical rectangle (Call Stack) $\leftrightarrow$ Circular arrow (Event Loop) $\leftrightarrow$ 2 horizontal queues: (1) Microtask Queue (Promises), (2) Macrotask Queue (setTimeout). Write priority rule: Stack Empty -> All Microtasks -> 1 Macrotask.
📖 Skolnik Ch. 4 • Introduction to Radar Systems

MTI Radar Delay Line Canceller

6 Marks • Q5/Q6

Cancels stationary ground clutter by subtracting previous pulse echoes from the current pulse echo. Stationary echo signals have zero Doppler shift and cancel completely ($V(t) - V(t-T) = 0$), whereas moving targets with Doppler frequency $f_d$ pass through.

✏️ 30-Second Exam Blackboard Draft:
Draw split line: Top path direct to ($+$) terminal of circle; Bottom path through box labeled [Delay T = 1/PRF] to ($-$) terminal. Formula: Blind speed vb = n·λ·PRF / 2.
📖 Buyya Ch. 3 • Mastering Cloud Computing

Type-1 (Bare Metal) vs Type-2 (Hosted) Stack

6 Marks • Q3/Q4

Type-1 (Bare-Metal) installs directly onto physical server hardware with zero host OS overhead, giving near-native performance for AWS/Azure datacenters. Type-2 (Hosted) runs as software inside a host OS, incurring double-kernel virtualization overhead.

✏️ 30-Second Exam Blackboard Draft:
Draw 2 stacked towers side-by-side. Left: Hardware $\to$ Hypervisor $\to$ VMs. Right: Hardware $\to$ Host OS $\to$ Hypervisor $\to$ VMs. Mention: Type-1 = VMware ESXi, Xen | Type-2 = VirtualBox, VMware Workstation.
