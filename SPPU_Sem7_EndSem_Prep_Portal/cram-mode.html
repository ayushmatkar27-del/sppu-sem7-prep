📍 UNIT 3: Waveguide Components & Ferrite Devices (End-Sem Q1/Q2)

100% Guaranteed 6 Marks

Magic Tee: Properties & [S]-Matrix Derivation

S = (1/√2) · [ 0, 0, 1, 1 ; 0, 0, 1, -1 ; 1, 1, 0, 0 ; 1, -1, 0, 0 ]
  • Port 1 & 2 (Collinear): S11 = S22 = 0 when perfectly matched.
  • Port 3 (H-plane sum Σ): Signal entering Port 3 divides into 1 and 2 in equal magnitude and in-phase (S13 = S23 = 1/√2).
  • Port 4 (E-plane difference Δ): Signal entering Port 4 divides into 1 and 2 in equal magnitude, 180° out of phase (S14 = -S24 = 1/√2).
  • Cross-Isolation: Port 3 and 4 are completely isolated (S34 = S43 = 0; S12 = 0).
Highly Repetitive 6 Marks

Two-Hole Directional Coupler (Coupling, Directivity, Isolation)

d = λ_g / 4 | C = 10 log10(P1/P4) | D = 10 log10(P4/P3) | I = 10 log10(P1/P3) = C + D
  • Construction: Two rectangular waveguides joined along broad wall with two small aperture holes spaced d = λ_g / 4 apart.
  • Forward Direction (Port 4): Both aperture waves travel the exact same total path distance; they arrive IN-PHASE and add vectorially.
  • Backward Direction (Port 3): Wave via hole 2 travels an extra 2d = λ_g / 2 (180° phase shift); waves arrive 180° OUT-OF-PHASE and cancel completely!
Must Score 6 Marks

Ferrite Isolator & Circulator (Faraday Rotation Non-Reciprocity)

Isolator: S12 = 0, S21 = 1 | Circulator: 1 → 2 → 3 → 1 (S31 = S12 = S23 = 1)
  • Ferrite Material: Non-conducting magnetic ceramics (Fe2O3 with Mn/Zn/Ni). Under static DC magnetic field, exhibits gyromagnetic precession.
  • Faraday Rotation: Plane of polarization rotates as wave travels through magnetized ferrite rod. Rotation angle θ = V · B · l is non-reciprocal (continues rotating in same spatial direction regardless of wave propagation direction!).
  • Isolator: Allows forward transmission from source to load (0 dB loss), absorbs reflected power from load in resistive card (prevents source pulling).

📍 UNIT 4: Microwave Tubes & Amplifiers (End-Sem Q3/Q4)

100% Guaranteed 6 Marks

Limitations of Conventional Vacuum Tubes at Microwaves

Transit Time τ = d / v_0 ≈ T | Input Conductance G_in ∝ f² | X_C = 1/2πfC → 0 | X_L = 2πfL → ∞
  • Transit Time Effect: When transit time τ becomes comparable to signal period T, electrons absorb power from grid during transit, causing heavy input conductance loading (Gain plummets).
  • Interelectrode Capacitance: Lowers reactance, short-circuiting high-frequency RF signals between electrodes.
  • Lead Inductance: Wire pin inductances create huge degenerative feedback reactances.
  • Solution: Microwave velocity-modulation tubes (Klystron, Magnetron, TWT) use transit time constructively!
Highly Repetitive 6 Marks

Reflex Klystron: Mechanism & Applegate Diagram

Transit Time Mode: T_0 = (n + 3/4) · T | Modes: n = 1 (1¾), n = 2 (2¾) | Max Efficiency = 58.4%
  • Single Resonant Cavity: Serves as both buncher and catcher. Repeller electrode held at high negative potential (-V_r).
  • Velocity Modulation: Early electrons accelerated, reference electrons unchanged, late electrons decelerated in cavity gap.
  • Applegate Diagram: In repeller space, faster electrons penetrate deeper and take longer path; slower electrons reverse sooner. All converge into a single dense electron bunch returning at the cavity grid!
  • Optimum Phase: Bunches must enter cavity during retarding RF phase to transfer kinetic energy to cavity RF electric field.
Highly Repetitive 6-8 Marks

Cavity Magnetron: Crossed-Field (E ⊥ B), π-Mode & Strapping

Hull Cut-Off: B_0 = √[ (8m·V_0) / (e·b² · (1 - a²/b²)²) ] | Phase Shift Between Cavities = 180° (π)
  • Crossed-Field Geometry: Radial DC electric field Er ⊥ Axial static magnetic field Bz. Electrons experience curved cycloidal trajectories under Lorentz force.
  • π-Mode Operation: Adjacent anode resonator cavities oscillate with 180° (π radians) phase difference. Form rotating electron "spokes" that transfer DC energy into cavity RF oscillations.
  • Strapping: Two copper rings interconnecting alternate anode vanes to lock frequency in the desired π-mode and eliminate mode-jumping.
Must Score 6 Marks

Travelling Wave Tube Amplifier (TWTA) vs Klystron

Slow-Wave Helix: v_p = c · (p / πd) ≈ 0.1c | TWTA Bandwidth: 1-2 Octaves (Broadband)
  • Slow-Wave Helix: Reduces axial phase velocity of microwave wave to match electron beam velocity (vp ≈ ve).
  • Continuous vs Discrete Interaction: TWTA interacts continuously along full length of helix; Klystron interacts discretely only inside narrow cavity gaps.
  • Bandwidth: TWTA has extremely wide bandwidth (> 30-50%); Klystron is narrowband (< 1-2%).

📍 UNIT 5: Solid-State Microwave Devices & Measurements (End-Sem Q5/Q6)

100% Guaranteed 6-8 Marks

Gunn Diode: RWH Two-Valley Mechanism & Domain Dynamics

ΔE = 0.36 eV | E_th ≈ 3.2 kV/cm for GaAs | Drift Frequency: f = v_d / L
  • No P-N Junction: Bulk slice of compound semiconductor (GaAs or InP).
  • RWH Model: Conduction band has two sub-bands: Lower valley (Γ) has light effective mass (m1* = 0.068 m0) and high mobility (μ1 ≈ 8000 cm²/V·s); Upper valley (L) has heavy mass (m2* = 1.2 m0) and low mobility (μ2 ≈ 180 cm²/V·s).
  • Negative Differential Resistance: Above Eth, electrons scatter to upper valley, current drops as field increases (dv/dE < 0). High-field domain forms at cathode and drifts to anode.
Highly Repetitive 6 Marks

IMPATT & TRAPATT Diodes: Avalanche Transit Time

Total Phase Shift = 90° (Avalanche) + 90° (Drift) = 180° Out-of-Phase (Dynamic -R)
  • IMPATT (Read Diode): Reverse-biased p+-n-i-n+ structure. Impact avalanche ionization generates 90° delay between RF voltage and hole-electron current; drift through intrinsic region adds second 90° delay → 180° total phase lag.
  • TRAPATT: Trapped Plasma Avalanche Triggered Transit mode. Operates in plasma state with massive carrier extraction; gives high efficiency (~75%) at lower frequencies (< 10 GHz) vs IMPATT (~15%).
Standard 6-8 Marks

VSWR Measurement: Low vs High (Double Minimum Method)

For Low VSWR (< 10): S = V_max / V_min | For High (> 10): S = λ_g / [ π · (d2 - d1) ]
  • Low VSWR Setup: Slotted line waveguide section; probe directly records maximum voltage crest (Vmax) and minimum voltage trough (Vmin).
  • High VSWR Limitation: Direct Vmin is near zero, drowned by detector noise and probe square-law distortion.
  • Double Minimum Method: Position probe at minimum, then move left (d1) and right (d2) to points where detector reading doubles (twice minimum power / 3 dB). Difference Δd = |d2 - d1| calculates exact high VSWR!

📍 UNIT 6: RADAR Systems, Applications & Hazards (End-Sem Q7/Q8)

100% Guaranteed 6-8 Marks

Fundamental Radar Range Equation Derivation

R_max = [ (P_t · G · A_e · σ) / ( (4π)² · S_min ) ]^(1/4) | R_max ∝ (P_t)^(1/4)
  • Step 1: Transmitted power density at range R: S_iso = Pt / (4πR²); with gain G: S_target = Pt·G / (4πR²).
  • Step 2: Power reradiated by target with cross section σ: P_scattered = [Pt·G·σ] / (4πR²).
  • Step 3: Reflected echo power density at radar: S_echo = P_scattered / (4πR²) = [Pt·G·σ] / [(4π)²·R⁴].
  • Step 4: Captured by antenna aperture Ae: Pr = S_echo · Ae. Setting Pr = S_min yields fundamental 4th-root Radar Range Equation!
Core Concept 6 Marks

MTI Radar, Delay Line Canceller & Blind Speeds

Doppler Shift f_d = 2·v_r / λ | Blind Speeds: v_b = (n · λ · PRF) / 2 | (n = 1, 2, 3...)
  • Moving Target Indicator (MTI): Eliminates massive stationary ground clutter echoes using Doppler frequency shift.
  • Delay Line Canceller: Current pulse echo is subtracted from previous pulse delayed by exactly T = 1/PRF. Stationary targets cancel to zero; moving targets yield non-zero difference.
  • Blind Speeds: Radial velocities where Doppler shift equals integer multiple of PRF (fd = n·PRF); output cancels completely, making moving aircraft invisible! Prevented by PRF staggering.
Must Score 6 Marks

Microwave Biological Hazards & Radiation Standards

Specific Absorption Rate SAR = (σ · |E|²) / (2 · ρ) [W/kg] | Safety Limit: 10 mW/cm² (OSHA/ANSI)
  • Thermal Effects: Microwave EM waves cause dielectric heating of water molecules in biological tissue, raising localized temperatures.
  • Vulnerable Organs: Eyes (cataract formation due to poor blood flow/cooling in lens) and Testes (sterility).
  • Safety Standards: Maximum Permissible Exposure (MPE) = 10 mW/cm² for occupational workers; SAR safety limit = 0.4 W/kg whole-body average.

📍 UNIT 3: PLDs, CPLD & FPGA Architectures (End-Sem)

100% Guaranteed (15x Across 7 Papers) 6/8 Marks

CPLD vs FPGA Architectural & Feature Comparison

CPLD: Coarse-Grained (Macrocells + Global Interconnect) | FPGA: Fine-Grained (LUTs + Segmented Mesh)
  • Architecture: CPLD uses SPLD-like Macrocells connected to a central Global Interconnect Matrix. FPGA uses an array of thousands of Configurable Logic Blocks (CLBs).
  • Logic Implementation: CPLD relies on wide PAL/PLA-like AND-OR arrays (wide SOP expressions, 16+ inputs). FPGA relies on Small Look-Up Tables (LUT4 or LUT6).
  • Timing Predictability: CPLD delay is 100% deterministic (pin-to-pin delay known in advance). FPGA delay is non-deterministic (depends heavily on place-and-route).
  • Storage & Volatility: CPLD is Non-Volatile (EEPROM/Flash based, boots instantly). FPGA is Volatile (SRAM-based, requires external boot PROM on power-up).
  • Standby Power: CPLD consumes ultra-low standby power; FPGA has higher quiescent static leakage current.
75% Frequency (10x) 6 Marks

Classification of PLDs (PROM, PAL, PLA, CPLD, FPGA)

PROM: Fixed AND, Prog OR | PAL: Prog AND, Fixed OR | PLA: Prog AND, Prog OR
  • PROM: Decodes all 2^n minterms with fixed AND array; only OR array is programmable. Inefficient for logic functions with few minterms.
  • PAL (Programmable Array Logic): Programmable AND array feeds fixed OR gates (typically 2-4 AND gates per OR gate). Fast, inexpensive, widely used.
  • PLA (Programmable Logic Array): Both AND and OR arrays are fully programmable. Maximum flexibility, but slower propagation delay due to dual programmable fuses.
  • CPLD & FPGA: High-density evolutionary extensions integrating multiple PAL-like function blocks or distributed LUT matrices with programmable routing channels.
75% Frequency (9x) 6/8 Marks

FPGA Architecture: CLB, LUT, Switch Matrix & IOB

CLB = 2-4 Slices (LUTs + Multiplexers + Dedicated Flip-Flops + Fast Carry Logic)
  • Configurable Logic Block (CLB): Core functional building block containing Look-Up Tables (LUTs) that implement any arbitrary Boolean function of 4 or 6 variables via SRAM truth table addressing.
  • Programmable Interconnect: Horizontal and vertical routing channels interconnected by Switch Matrices (SM) and Connection Blocks (CB) using pass transistors or transmission gates.
  • Input/Output Blocks (IOB): Configurable pads supporting multi-standard voltages (LVTTL, LVCMOS, PCI, differential LVDS) with programmable slew rate, pull-up/down resistors, and input/output registers.

📍 UNIT 4: CMOS Logic Design, Scaling & Non-Idealities (End-Sem)

85% Frequency (13x) 6/8 Marks

CMOS Logic Implementation & Aspect Ratio (W/L) Sizing

Symmetric Inverter: (W/L)_p = 2.5 · (W/L)_n | Series: W_eff = W / k | Parallel: W_eff = k · W
  • Complementary Structure: Pull-Up Network (PUN) of PMOS transistors connected to VDD; Pull-Down Network (PDN) of dual NMOS transistors connected to GND.
  • Mobility Difference: Electron mobility μ_n ≈ 500 cm²/V·s is ~2.5 times hole mobility μ_p ≈ 200 cm²/V·s, requiring PMOS width to be 2 to 3 times NMOS width for equal rise and fall propagation delays (tpLH = tpHL).
  • Equivalent Sizing: For k transistors in series, width must be multiplied by k to preserve equivalent on-resistance. In parallel, width is unchanged while effective resistance is halved.
80% Frequency (10x) 6 Marks

Transmission Gate (TG) & Multiplexer Transistor Savings

TG = NMOS + PMOS in Parallel (Control S and S_bar) | Passes Full Rail-to-Rail Logic (0V to VDD)
  • Threshold Drop Fix: An isolated NMOS passes a weak logic 1 (VDD - Vtn); an isolated PMOS passes a weak logic 0 (|Vtp|). A Transmission Gate connects both in parallel to pass full rail-to-rail swing with low dynamic on-resistance across all voltage levels.
  • 2:1 Multiplexer Savings: Built with 2 TGs + 1 control inverter = 6 transistors (compared to 12 transistors in standard static CMOS NAND-NAND implementation).
  • 4:1 Multiplexer Savings: Built with 4 TGs or cascaded 2:1 stages = 10-14 transistors (compared to 36 transistors in static CMOS logic), saving massive silicon real estate and power.
85% Frequency (11x) 6/8 Marks

Short-Channel Effects (Velocity Saturation, CLM, DIBL, HCI, Punch-Through)

DIBL: ΔV_th = -η · V_DS | Velocity Saturation: I_Dsat = W · C_ox · v_sat · (V_GS - V_th)
  • Velocity Saturation: High longitudinal electric field causes carrier drift velocity to plateau at v_sat ≈ 10^7 cm/s, changing drain current from quadratic (V_GS - V_th)^2 to strictly linear.
  • Drain-Induced Barrier Lowering (DIBL): High drain voltage depletes the channel laterally, lowering the potential barrier at the source, causing threshold voltage (V_th) to drop and subthreshold leakage to soar.
  • Channel Length Modulation (CLM): Effective channel length shortens (ΔL) in saturation, causing non-zero output conductance (g_ds = λ · I_D).
  • Hot Carrier Injection (HCI): High-energy electrons tunnel into gate oxide, causing permanent threshold voltage shifts and oxide degradation over device lifetime.
  • Punch-Through: Drain depletion region physically merges with source depletion region, bypassing gate control completely.
70% Frequency (9x) 6 Marks

CMOS Latch-Up Effect: Mechanism & Layout Prevention Rules

Condition: Loop Gain β_npn · β_pnp >= 1 Creates Low-Impedance Path from VDD to GND
  • Parasitic SCR Formation: In bulk CMOS, the p+ source/drain, n-well, p-substrate, and n+ source/drain form cross-coupled parasitic lateral npn and vertical pnp bipolar transistors.
  • Trigger: Voltage spikes or substrate noise turn ON one BJT; collector current drives base of other BJT, locking into runaway high-current conduction that destroys the IC.
  • Prevention Rules: Place Guard Rings (well/substrate taps) surrounding all diffusion regions; use heavily doped epitaxial substrates; minimize substrate resistance R_sub and well resistance R_well with frequent VDD and GND pick-ups.

📍 UNIT 5: Physical Design, Stick Diagrams & Layout Rules (End-Sem)

80% Frequency (11x) 6 Marks

Lambda (λ) Based Design Rules (Mead-Conway Rules)

λ = Resolution Half-Pitch (Linear Scaling Metric) | Contact Window: 2λ × 2λ
  • Why Lambda Rules: Express layout geometry (widths, spacings, overlaps) in terms of dimensionless scalable unit λ, allowing designs to easily translate across shrinking foundry generations without complete redraw.
  • Key Mead-Conway Rules: Minimum Poly width = 2λ; Poly spacing = 2λ; Diffusion width = 2λ; Diffusion spacing = 3λ; Poly overlap of Diffusion (extension) = 2λ; Metal-1 width = 3λ; Metal-1 spacing = 3λ; Contact cut size = 2λ × 2λ; Metal overlap of contact = 1λ.
  • Micron Rules: Industry foundries enforce absolute micron rules for sub-micron nodes to extract maximum packing density.
80% Frequency (10x) 6/8 Marks

Stick Diagrams & Euler's Path for Minimum Parasitic Area

Euler Path: Traverses every edge exactly once | Yields Uninterrupted Diffusion Strip
  • Color Coding: Green = n-diffusion; Yellow/Brown = p-diffusion; Red = Polysilicon; Blue = Metal-1; Black 'X' = Contact cut; Demarcation line = separates PUN and PDN.
  • Euler's Path Algorithm: Construct dual graphs for PMOS pull-up and NMOS pull-down networks. Find a common Eulerian sequence of transistor input gate labels that can be traversed continuously without backtracking.
  • Advantage: Eliminates internal diffusion breaks and isolation oxide gaps, drastically minimizing source/drain junction parasitic capacitance and total chip layout area.
70% Frequency (9x) 6 Marks

Layout Parasitics: Antenna Effect, Crosstalk & Electromigration

Black's Equation: MTTF = A · J^(-n) · exp(E_a / kT) | Crosstalk: ΔV = V_swing · (C_c / (C_c + C_gnd))
  • Antenna Effect (Plasma Induced Damage): Long metal wires collect static charge during reactive ion plasma etching. Discharges through thin gate oxide, blowing dielectric breakdown. Fixed by inserting reverse-biased Antenna Diodes or jumper metal layer hopping.
  • Crosstalk: Parasitic coupling capacitance (C_c) between parallel adjacent routing tracks injects noise glitches into victim nets or causes dynamic delay jitter. Mitigated by shielding with VDD/GND tracks and wire spacing.
  • Electromigration: High current density (J > 1-2 MA/cm²) momentum transfers from electron wind to metal ions, creating voids (open circuit) and hillocks/whiskers (short circuit). Solved by widening power rails and adding redundant vias.

📍 UNIT 6: Fault Modeling, Design for Testability (DFT) & Boundary Scan (End-Sem)

85% Frequency (12x) 6/8 Marks

Design for Testability (DFT): Controllability, Observability & SCOAP

Testability = Controllability × Observability | SCOAP: CC0(n), CC1(n), and CO(n)
  • Controllability: Measure of difficulty of setting an internal circuit node to a desired logic value ('0' or '1') by asserting primary inputs.
  • Observability: Measure of difficulty of propagating the logic state of an internal circuit node to primary outputs for measurement.
  • SCOAP Analysis: Sandia Controllability/Observability Analysis Program computes Combinational Controllability 0/1 and Combinational Observability step counts, pinpointing test bottlenecks.
  • Scan Path Design: Replaces normal D-flip-flops with multiplexed Scan Flip-Flops (normal vs shift mode), chaining internal storage elements into long shift registers to make internal sequential states directly controllable and observable.
75% Frequency (10x) 6/8 Marks

Built-In Self-Test (BIST) Architecture: LFSR, PRPG, MISR & BILBO

Primitive Polynomial: Generates Maximal-Length (2^n - 1) Pseudo-Random Test Vector Sequence
  • BIST Core Architecture: On-chip Test Pattern Generator (TPG), Circuit Under Test (CUT), Output Response Analyzer (ORA), and BIST Controller.
  • LFSR (Linear Feedback Shift Register): Generates pseudo-random test vectors using feedback XOR taps governed by primitive polynomials.
  • MISR (Multiple Input Signature Register): Compresses multi-output responses into a unique compact signature (e.g., 32-bit), compared against golden fault-free reference.
  • BILBO (Built-In Logic Block Observer): 4-mode reconfigurable register: (1) Normal parallel register, (2) Scan register, (3) PRPG pattern generator, (4) MISR signature compressor.
85% Frequency (11x) 6/8 Marks

JTAG Boundary Scan (IEEE 1149.1) & TAP Controller

5 Dedicated Pins: TCK, TMS, TDI, TDO, TRST* | 16-State TAP Finite State Machine
  • Boundary Scan Architecture: Places Boundary Scan Cells (BSCs) around every I/O pad, forming a serial ring around the chip boundary for board-level testing without physical bed-of-nails test probes.
  • TAP Controller: 16-state synchronous FSM driven entirely by TMS on rising edge of TCK. Transitions between Test-Logic-Reset, Run-Test/Idle, Select-DR-Scan, Capture-DR, Shift-DR, Exit1-DR, Pause-DR, Exit2-DR, Update-DR.
  • Mandatory JTAG Instructions: BYPASS (1-bit shift register bypass for faster testing of other chips), SAMPLE/PRELOAD (captures normal I/O signals without interrupting chip operation), EXTEST (tests inter-chip board solder connections and PCB traces). Optional: INTEST, IDCODE.

📍 UNIT 3 & 4: Virtualization, Storage & AWS Architecture

100% Guaranteed 6 Marks

Type-1 vs Type-2 Hypervisors & Full vs Para Virtualization

Type-1: Bare-Metal (ESXi, Xen, KVM) | Type-2: Hosted (VirtualBox, VMware Workstation)
  • Type-1 (Bare Metal): Runs directly on physical hardware; superior performance, low overhead, preferred in enterprise cloud datacenters.
  • Type-2 (Hosted): Runs on top of an existing host OS; introduces double OS overhead, used for desktop development.
  • Full Virtualization: Guest OS unmodified; hypervisor traps and emulates sensitive instructions (binary translation / hardware VT-x).
  • Para-virtualization: Guest OS kernel modified with hypercalls directly to hypervisor for higher I/O throughput.
100% Guaranteed 6/8 Marks

AWS Core Ecosystem: EC2, S3, EBS, and VPC

Storage: S3 (Object, 11 9's durability) | EBS (Block, Persistent SAN for EC2)
  • EC2 (Elastic Compute Cloud): Resizable compute virtual instances with pricing models: On-Demand, Reserved, Spot.
  • S3 (Simple Storage Service): Highly scalable object store with buckets, versioning, lifecycle policies, and 99.999999999% durability.
  • VPC (Virtual Private Cloud): Logically isolated virtual network with public/private subnets, Internet Gateways, NAT Gateways, and Security Groups.

📍 UNIT 5 & 6: Docker/Kubernetes & Cloud Security

100% Guaranteed 6 Marks

Docker vs Virtual Machines & Container Architecture

Containers: Shared Host Kernel + cgroups/namespaces | VMs: Full Guest OS + Hypervisor
  • Resource Isolation: Containers use Linux kernel features: Namespaces (isolation of PID, net, mount) and Cgroups (CPU/RAM limits).
  • Startup Speed: Containers start in milliseconds vs VMs taking minutes due to full OS boot sequence.
  • Image Layers: Docker builds images with copy-on-write (CoW) layered filesystem, maximizing caching and storage efficiency.
Must Score 6 Marks

AWS Shared Responsibility Model & IAM

AWS owns "Security OF the Cloud" | Customer owns "Security IN the Cloud"
  • Security OF the Cloud (AWS): Physical data center security, host hardware, hypervisors, global networking facilities.
  • Security IN the Cloud (Customer): Guest OS patching, firewall rules (Security Groups), IAM user roles, data encryption at rest and in transit.
  • IAM Principle of Least Privilege: Grant users, groups, and roles only the exact permissions needed via JSON policy documents.

📍 UNIT 3 & 4: CNNs, Regularization & Optimizers

100% Guaranteed 6 Marks

CNN Architecture: Convolution, Pooling, and Parameter Sharing

Output Size O = ⌊ (W - K + 2P) / S ⌋ + 1 | Params = (K_h * K_w * C_in + 1) * C_out
  • Parameter Sharing: Same convolution kernel weights are slid across the entire image, drastically cutting down parameter count compared to dense FC layers.
  • Local Receptive Field: Each neuron connects only to a small localized spatial patch of the input, capturing local edges and textures.
  • Pooling: Max or Average pooling downsamples spatial dimensions, introduces translation invariance, and controls overfitting.
High Frequency 6 Marks

Batch Normalization vs Dropout Regularization

BN: x̂ = (x - μ_B) / √(σ_B² + ε), y = γ*x̂ + β | Dropout: r ~ Bernoulli(p)
  • Batch Normalization: Normalizes mini-batch activations to zero mean and unit variance. Mitigates Internal Covariate Shift, enables higher learning rates.
  • Learnable Parameters: Scale (γ) and shift (β) restore representational capacity of the layer.
  • Dropout: Randomly deactivates neurons during training with probability p, preventing co-adaptation of features. Scales weights by p during inference.

📍 UNIT 5 & 6: RNNs, LSTM & Autoencoders

100% Guaranteed 6/8 Marks

LSTM Architecture & 3 Gating Equations

f_t = σ(W_f·[h,x] + b_f), i_t = σ(W_i·[h,x] + b_i), o_t = σ(W_o·[h,x] + b_o)
  • Forget Gate (f_t): Decides what proportion of information to throw away from prior cell state C_{t-1}.
  • Input Gate (i_t): Decides which new candidate values (C̃_t = tanh(W_c·[h,x])) to update into the memory cell: C_t = f_t*C_{t-1} + i_t*C̃_t.
  • Output Gate (o_t): Filters current cell state through tanh to output next hidden state h_t = o_t * tanh(C_t).
  • Constant Error Carousel: The additive linear update of C_t cures the Vanishing Gradient Problem of vanilla RNNs.
Standard 6 Marks

Autoencoders vs GANs (Generative Adversarial Networks)

GAN Minimax Game: min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]
  • Autoencoder: Unsupervised network comprising Encoder (compresses input x to latent bottleneck z) and Decoder (reconstructs x̂ from z). Minimizes MSE reconstruction loss.
  • GAN: Two competing networks: Generator G (creates realistic synthetic data from random noise z) and Discriminator D (classifies real vs fake).
  • Training Dynamic: Nash equilibrium zero-sum game. Discriminator learns to maximize accuracy; Generator learns to fool D.

📍 UNIT 3 & 4: Closures, Event Loop & Promises

100% Guaranteed 6 Marks

JavaScript Closures & Lexical Scoping

function makeCounter() { let c = 0; return () => ++c; } // 'c' persists in heap!
  • Definition: A closure is a function bundled together with references to its surrounding lexical environment, allowing it to remember outer variables even after the outer function has returned.
  • Use Cases: Data encapsulation (private variables), function currying, event listeners, and memoization.
  • Memory Caveat: Variables in closures are not garbage-collected as long as the inner function reference is retained in memory.
100% Guaranteed 6 Marks

Event Loop, Call Stack & Microtask Queue

Priority Order: Call Stack -> Microtask Queue (Promises) -> Macrotask Queue (setTimeout)
  • Call Stack: Single-threaded LIFO execution stack for synchronous function calls.
  • Microtask Queue: Holds Promise.then, queueMicrotask, MutationObserver callbacks. Executed immediately after stack empties, BEFORE any macrotask!
  • Macrotask Queue: Holds setTimeout, setInterval, setImmediate, and I/O callbacks. Event loop pulls one macrotask per tick.

Promises vs Async/Await & Error Handling

async function get() { try { const d = await fetch(u); } catch(e) { console.error(e); } }
  • Promise States: Pending -> Fulfilled (with value) OR Rejected (with reason). Immutable once settled.
  • Async/Await: Syntactic sugar built over Promises. Enables asynchronous non-blocking code to be read and written like synchronous code.
  • Error Handling: Standard try...catch blocks cleanly catch both synchronous runtime errors and rejected async Promises.

Node.js Express REST API & Middleware Pipeline

app.use((req, res, next) => { console.log(req.method); next(); });
  • Middleware Pattern: Functions with access to (req, res, next) chained sequentially. Must invoke next() to pass control down the pipeline.
