Implementation #1. 4:1 Multiplexer in VHDL (Behavioral & Dataflow)

A 4:1 Multiplexer selects one of 4 input lines (I0, I1, I2, I3) using 2 select lines (S1, S0) to drive a single output line Y.

📘 1. Detailed Production / Structural Model (Full Architecture) 
-- Library declaration
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

-- Entity Definition
entity Mux4to1 is
    Port (
        I : in  STD_LOGIC_VECTOR (3 downto 0); -- 4 Inputs (I3, I2, I1, I0)
        S : in  STD_LOGIC_VECTOR (1 downto 0); -- 2 Select Lines (S1, S0)
        Y : out STD_LOGIC                      -- Single Output
    );
end Mux4to1;

-- Architecture: Behavioral Modeling using CASE statement
architecture Behavioral of Mux4to1 is
begin
    process(I, S)
    begin
        case S is
            when "00" => Y <= I(0);
            when "01" => Y <= I(1);
            when "10" => Y <= I(2);
            when "11" => Y <= I(3);
            when others => Y <= '0';
        end case;
    end process;
end Behavioral;
Technical Concepts & Sizing Notes:
  • Sensitivity list process(I, S) triggers the block whenever inputs or select lines transition.
  • Always include the when others clause in VHDL case statements to prevent latch inference.
⚡ 2. Exam Short Form (Super Simple & Short — Memorize & Write in 2 Minutes) 
-- --- EXAM SHORT FORM (VHDL Dataflow - 5 Lines) ---
library IEEE; use IEEE.STD_LOGIC_1164.ALL;
entity mux4 is port(I: in bit_vector(3 downto 0); S: in bit_vector(1 downto 0); Y: out bit); end;
architecture arch of mux4 is
begin
    Y <= I(0) when S="00" else I(1) when S="01" else I(2) when S="10" else I(3);
end arch;

Implementation #2. D Flip-Flop with Synchronous and Asynchronous Reset in VHDL

D Flip-Flop latches data input D at clock edges. Asynchronous reset takes effect immediately regardless of the clock, whereas synchronous reset waits for the active clock edge.

📘 1. Detailed Production / Structural Model (Full Architecture) 
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity D_FF is
    Port (
        clk   : in  STD_LOGIC;
        reset : in  STD_LOGIC; -- Active-High Asynchronous Reset
        D     : in  STD_LOGIC;
        Q     : out STD_LOGIC
    );
end D_FF;

architecture Behavioral of D_FF is
begin
    -- Asynchronous Reset: 'reset' must be in the sensitivity list!
    process(clk, reset)
    begin
        if reset = '1' then
            Q <= '0';                    -- Cleared immediately
        elsif rising_edge(clk) then
            Q <= D;                      -- Latches data on rising clock edge
        end if;
    end process;
end Behavioral;
Technical Concepts & Sizing Notes:
  • For Asynchronous Reset, reset is checked outside the clock edge condition.
  • For Synchronous Reset, the condition would be: if rising_edge(clk) then if reset='1' then Q<='0'; else Q<=D; end if; end if;.
⚡ 2. Exam Short Form (Super Simple & Short — Memorize & Write in 2 Minutes) 
-- --- EXAM SHORT FORM (D Flip-Flop VHDL) ---
library IEEE; use IEEE.STD_LOGIC_1164.ALL;
entity dff is port(clk, rst, D: in std_logic; Q: out std_logic); end;
architecture rtl of dff is
begin
    process(clk, rst) begin
        if rst='1' then Q <= '0';
        elsif rising_edge(clk) then Q <= D;
        end if;
    end process;
end rtl;

Implementation #3. CMOS Inverter SPICE Netlist & Transistor Simulation Model

A CMOS inverter consists of an active PMOS pull-up connected between VDD and Out, and an active NMOS pull-down between Out and GND, driven by a common gate Input.

📘 1. Detailed Production / Structural Model (Full Architecture) 
* CMOS Inverter SPICE Subcircuit Netlist
* Syntax: M<name> <drain> <gate> <source> <bulk> <model> W=<width> L=<length>

.include 'tsmc018.param' * 180nm CMOS technology parameter file

* Voltage Sources
Vdd vdd 0 DC 1.8V
Vin in 0 PULSE(0V 1.8V 0ns 100ps 100ps 5ns 10ns)

* MOS Transistors (Sizing: PMOS W=4u, NMOS W=2u, L=0.18u)
M1 out in vdd vdd PMOS W=4.0u L=0.18u  * Pull-up Network
M2 out in 0   0   NMOS W=2.0u L=0.18u  * Pull-down Network

* Load Capacitance
Cload out 0 50fF

* Simulation Analysis Commands
.tran 10ps 20ns
.plot tran V(in) V(out)
.end
Technical Concepts & Sizing Notes:
  • PMOS width is chosen twice the NMOS width ($W_p = 2 W_n$) to compensate for lower hole mobility ($\mu_p \approx 0.5 \mu_n$).
  • This achieves equal rise and fall propagation delays ($t_{PLH} = t_{PHL}$) and a symmetric switching threshold ($V_{th} = V_{DD}/2$).

Implementation #4. 2-Input XOR Gate using Transmission Gates (TG)

Conventional static CMOS XOR requires 12 transistors. Using Transmission Gates, an XOR gate can be implemented with only 6 transistors (2 TGs + 1 Inverter).

📘 1. Detailed Production / Structural Model (Full Architecture) 
// Verilog Structural Model: 2-Input XOR using Transmission Gates
// Logic Equation: Y = A ^ B = A * ~B + ~A * B

module XOR_TG (
    input A,
    input B,
    output Y
);
    wire not_A;

    // Inverter for signal A
    not (not_A, A);

    // TG1: Passes B when A is LOW (A=0, not_A=1) -> Y = B
    // Syntax: cmos (out, in, ncontrol, pcontrol)
    cmos tg1 (Y, B, not_A, A);

    // TG2: Passes ~B when A is HIGH (A=1, not_A=0) -> Y = ~B
    wire not_B;
    not (not_B, B);
    cmos tg2 (Y, not_B, A, not_A);

endmodule
Technical Concepts & Sizing Notes:
  • When $A=0$, TG1 turns ON and passes $B$ to output $Y$ (since $0 \oplus B = B$).
  • When $A=1$, TG2 turns ON and passes $\bar{B}$ to output $Y$ (since $1 \oplus B = \bar{B}$).
  • Total Transistors: 2 inverters (4 transistors) + 2 TGs (4 transistors) = 8 transistors (or 6 without second inverter).
⚡ 2. Exam Short Form (Super Simple & Short — Memorize & Write in 2 Minutes) 
// --- EXAM SHORT FORM (Verilog TG XOR) ---
module xor_tg(input A, B, output Y);
    wire notA, notB;
    not(notA, A); not(notB, B);
    cmos tg1(Y, B, notA, A);    // Passes B when A=0
    cmos tg2(Y, notB, A, notA); // Passes ~B when A=1
endmodule

Implementation #5. Linear Feedback Shift Register (LFSR) for BIST Pattern Generation

LFSR is the fundamental pseudo-random pattern generator (PRPG) in Built-In Self-Test (BIST) designs, using a shift register with XOR feedback.

📘 1. Detailed Production / Structural Model (Full Architecture) 
-- 4-bit LFSR with characteristic polynomial: P(x) = x^4 + x^3 + 1
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity LFSR_4bit is
    Port (
        clk   : in  STD_LOGIC;
        reset : in  STD_LOGIC;
        Q     : out STD_LOGIC_VECTOR(3 downto 0)
    );
end LFSR_4bit;

architecture Behavioral of LFSR_4bit is
    signal reg : STD_LOGIC_VECTOR(3 downto 0) := "0001"; -- Seed state
begin
    process(clk, reset)
        variable feedback : STD_LOGIC;
    begin
        if reset = '1' then
            reg <= "0001"; -- Seed value (NEVER reset to all-zeros!)
        elsif rising_edge(clk) then
            -- Feedback XOR tap from Q(3) and Q(2)
            feedback := reg(3) xor reg(2);
            reg <= reg(2 downto 0) & feedback; -- Shift left and insert feedback
        end if;
    end process;

    Q <= reg;
end Behavioral;
Technical Concepts & Sizing Notes:
  • An $n$-bit maximal length LFSR produces a repeating pseudo-random sequence of $2^n - 1$ states.
  • The all-zeros state ('0000') is an illegal locked state and must never be used as a seed.
⚡ 2. Exam Short Form (Super Simple & Short — Memorize & Write in 2 Minutes) 
-- --- EXAM SHORT FORM (4-bit LFSR) ---
process(clk, rst) begin
    if rst='1' then q <= "0001"; -- Seed
    elsif rising_edge(clk) then
        q <= q(2 downto 0) & (q(3) xor q(2));
    end if;
end process;
