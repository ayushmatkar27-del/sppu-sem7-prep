Q1. What is an Anonymous Function in JavaScript? Explain its use with an example.
Appeared in: Nov/Dec 2022, May/Jun 2023, Nov/Dec 2023, May/Jun 2024, Nov/Dec 2024, May/Jun 2025, Nov/Dec 2025, May/Jun 2026
💡 Simple Analogy to Remember: Think of a normal function like a person with a nametag (e.g., "Alice"). An Anonymous Function is like a worker hired for a single quick job without a name badge—they do the work immediately and don't need to be called by name again!

1. Definition (1.5 Marks)

An Anonymous Function is simply a function that has no name (identifier). In standard JavaScript, you declare functions with a name like function add(), but an anonymous function is written without any name after the function keyword.

Because it doesn't have a name, it is usually stored inside a variable, passed as a callback argument to another function, or run immediately.

2. Syntax Comparison (1 Mark)

Regular Named Function Anonymous Function (Assigned to Variable)
function greet(name) {
  return "Hello " + name;
}		 var greet = function(name) {
  return "Hello " + name;
};

3. Why and Where is it Used? (1.5 Marks)

  • Function Expressions: Storing functional code in a variable so it can be passed around like data.
  • Event Handlers & Callbacks: Running quick code when a user clicks a button without creating an unnecessary named function.
  • Timers (setTimeout & setInterval): Executing a task after a delay.
  • IIFE (Immediately Invoked Function Expressions): Creating a private box of code so variables don't clash globally: (function() { ... })();

4. Complete Example Program to Write in Exam (2 Marks)

<!DOCTYPE html>
<html>
<body>
    <h2>Anonymous Function Demo</h2>
    <button id="calcBtn">Calculate Area</button>
    <p id="output"></p>

    <script>
        // Case 1: Anonymous function stored in a variable
        var getArea = function(width, height) {
            return width * height;
        };

        // Case 2: Anonymous function as an Event Listener Callback
        document.getElementById("calcBtn").addEventListener("click", function() {
            var result = getArea(10, 5);
            document.getElementById("output").innerHTML = 
                "Area of 10x5 Rectangle = " + result;
        });

        // Case 3: Anonymous function in a Timer (runs after 2 seconds)
        setTimeout(function() {
            console.log("Timer finished via anonymous function!");
        }, 2000);
    </script>
</body>
</html>
🎯 Examiner Tip for 6/6: Mention that anonymous functions are created at runtime, meaning they are not hoisted like regular function declarations. You cannot call them before the line where they are defined!

    • In JavaScript, typeof [] returns "object"! That's confusing because ordinary objects also return "object".

Q3. What is a Function? Explain with example how to pass and return parameters and arguments from called function to calling function.
Appeared in: Nov/Dec 2022, May/Jun 2023, Nov/Dec 2023, May/Jun 2026

1. Plain-English Concept Definitions (2 Marks)

  • Function: A named, reusable block of instructions that performs a specific job. Instead of rewriting code 10 times, you define a function once and call it whenever needed.
  • Calling Function (The Caller): The line of code that commands the function to run (e.g., calculateBill(100, 18);).
  • Called Function (The Worker): The actual function definition that executes the calculations.
  • Parameters vs. Arguments:
    • Parameters: The variable names written in the function definition header: function add(a, b) → a and b are parameters.
    • Arguments: The real values passed when calling it: add(10, 20) → 10 and 20 are arguments.
  • Return Statement: Sends the calculated answer back to the caller and exits the function immediately.

2. Visual Step-by-Step Flow (1 Mark)

[ Calling Code: var res = computeTotal(500, 50) ]
        |                               ^
  1. Sends Arguments (500, 50)          | 3. Returns Result (550)
        v                               |
[ Called Function: function computeTotal(price, tax) { return price + tax; } ]
        |
  2. Executes calculations internally

3. Full Working Program with Input & Return (3 Marks)

<script>
    // CALLED FUNCTION (Receives parameters: p, r, t)
    function calculateSimpleInterest(p, r, t) {
        // Input Validation
        if (p <= 0 || r <= 0 || t <= 0) {
            return "Error: Please enter positive values.";
        }

        // Perform computation
        var interest = (p * r * t) / 100;
        var totalAmount = p + interest;

        // Return an object containing both results back to the caller
        return {
            interestEarned: interest,
            finalBalance: totalAmount
        };
    }

    // CALLING CODE (Passes arguments: 10000, 7.5, 2)
    var principal = 10000;
    var rate = 7.5;
    var time = 2;

    // Calling the function and storing the returned value in 'statement'
    var statement = calculateSimpleInterest(principal, rate, time);

    console.log("Interest:", statement.interestEarned);  // 1500
    console.log("Final Balance:", statement.finalBalance); // 11500
</script>

Q4. What are common properties and methods of the Object in JavaScript?
Appeared in: Nov/Dec 2022, May/Jun 2023, Nov/Dec 2023, May/Jun 2026

1. Concept (1 Mark)

In JavaScript, almost everything is an Object! The top-level ancestor of all objects is Object.prototype. Every object you create automatically inherits its standard properties and helper methods.

2. Common Properties (1.5 Marks)

Property What it does (Simple Explanation) Quick Code Snippet
constructor Tells you which function created this object. var obj = {};
console.log(obj.constructor === Object); // true
__proto__ A pointer to the object's parent prototype (blueprint). console.log(obj.__proto__);
length Available in Array/String/Function objects to tell count. [1,2,3].length; // 3

3. Common Instance Methods (Inherited by all objects) (1.5 Marks)

Method Description Example
hasOwnProperty(prop) Checks if a property belongs directly to this object (not inherited from parent). car.hasOwnProperty("color"); // true
toString() Converts the object into a text/string format. ({a:1}).toString(); // "[object Object]"
valueOf() Returns the raw primitive value of the object. (new Number(50)).valueOf(); // 50

4. Super Useful Static Methods of Object (2 Marks)

These are called directly on the master Object keyword:

  • Object.keys(myObj): Extracts all key names into an array → Object.keys({name:"Ayush", age:21}) gives ["name", "age"].
  • Object.values(myObj): Extracts all values into an array → gives ["Ayush", 21].
  • Object.entries(myObj): Extracts key-value pairs as arrays of pairs → [["name", "Ayush"], ["age", 21]].
  • Object.freeze(myObj): Locks the object completely so nobody can add, delete, or change its properties.
  • Object.assign(target, source): Copies properties from one object to another (cloning).

Q5. Explain Data Types in JavaScript. Differentiate between Primitive and Non-Primitive data types.
Appeared in: Nov/Dec 2022, May/Jun 2023, Nov/Dec 2023, May/Jun 2026

1. The Two Main Families of Data Types (1.5 Marks)

JavaScript is a dynamically typed language. You do not need to specify int or float; JavaScript detects types automatically. All data types belong to two families:

  1. Primitive Data Types (Basic Single Values):
    • Number: Both integers and decimals (e.g., 25, 99.99).
    • String: Text inside quotes (e.g., "SPPU Exam").
    • Boolean: Logic flag (true or false).
    • Undefined: A variable declared but not assigned any value yet.
    • Null: An intentional empty / blank value.
    • BigInt & Symbol (Modern additions).
  2. Non-Primitive / Reference Types (Complex Collections):
    • Object, Array, Function, Date, RegExp.

2. Differentiation Table (Easy to Memorize for 6/6 Marks) (3 Marks)

Comparison Point Primitive Data Types Non-Primitive (Reference) Data Types
Where stored? Stored directly in the fast Stack Memory. Data is in Heap Memory; only its address pointer is on Stack.
Can it change? (Mutability) Immutable (The value itself cannot be modified in place). Mutable (You can add, edit, or delete object properties anytime).
Copy Behavior Copy by Value: Creates an independent separate copy. Changing copy does NOT affect original. Copy by Reference: Copies the memory address! Modifying the copy changes the original!
Comparison (===) Compares the actual value: 10 === 10 is true. Compares memory location: {} === {} is false (different addresses).
Examples Number, String, Boolean, Undefined, Null Objects, Arrays, Functions

3. Code Example Showing Copy by Value vs Reference (1.5 Marks)

// 1. Primitive: Copy by Value (Original is Safe)
var x = 100;
var y = x;  // Independent clone
y = 200;
console.log("x is still:", x); // Output: 100

// 2. Non-Primitive: Copy by Reference (Shared Address!)
var student1 = { name: "Rahul" };
var student2 = student1; // Copies pointer, points to SAME memory!
student2.name = "Ayush";
console.log("student1.name changed to:", student1.name); // Output: "Ayush"

Q6. Explain the concept of "Mask Out" with respect to functions in JavaScript.
Appeared in: May/Jun 2024, Nov/Dec 2024, May/Jun 2025
💡 Simple Analogy to Remember: Imagine you are at College and someone yells "Ayush!". Because there is an Ayush right inside your classroom (Local Scope), you assume they mean your classmate, not the Ayush sitting in the canteen outside (Global Scope). The classmate's presence "masks out" the outsider!

1. Definition of "Mask Out" (Scope Shadowing) (2 Marks)

Mask Out (also known in computer science as Variable Shadowing) happens when a local variable declared inside a function has the exact same name as a variable declared in the outer/global scope.

When this happens, the local variable takes priority inside that function and "masks out" (hides) the global variable from view. As long as you are inside the function, typing that variable name refers strictly to the local one.

2. Visual Diagram of Mask Out (1.5 Marks)

+---------------------------------------------------------+
| GLOBAL SCOPE: var city = "Pune"                         |
|                                                         |
|   +-------------------------------------------------+   |
|   | FUNCTION SCOPE: var city = "Mumbai" (MASKS OUT) |   |
|   |   console.log(city); // Prints: "Mumbai"        |   |
|   +-------------------------------------------------+   |
|                                                         |
|   console.log(city); // Prints: "Pune" (Unchanged!)     |
+---------------------------------------------------------+

3. Clean Working Example Program (2.5 Marks)

<script>
    // Global Variable
    var score = 50;

    function playGame() {
        // Local Variable with identical name
        // This 'score' MASKS OUT the outer global 'score'
        var score = 95;

        console.log("Inside function local score:", score); // Output: 95

        // How to still access the masked global variable in a browser?
        // Through the top-level 'window' object:
        console.log("Global score accessed via window:", window.score); // Output: 50
    }

    playGame();

    // Outside the function, the global variable is safe and untouched
    console.log("Outside function score:", score); // Output: 50
</script>
🎯 Exam Note: Explicitly mention that masking does not overwrite or destroy the global variable. It only hides it temporarily while that specific function is running.

Q7. Explain how a function is used as an object in JavaScript.
Appeared in: May/Jun 2024, Nov/Dec 2024, May/Jun 2025

1. Core Theory: Functions are "First-Class Objects" (2 Marks)

In many programming languages (like C or Java), functions are just executable blocks. But in JavaScript, functions are First-Class Citizens and actual Objects!

They are instances of the built-in Function object. Just like any normal object, a function can:

  • Have its own custom properties and methods attached to it.
  • Be assigned to variables, passed as arguments, and returned from other functions.
  • Be used as an Object Constructor to create brand new objects using the new keyword.

2. Attaching Properties Directly to a Function (2 Marks)

function car() {
    return "Vroom! Car is running.";
}

// Adding properties to the function object directly
car.brand = "Tesla";
car.model = "Model 3";
car.version = 2.0;

// Accessing properties like a regular object
console.log(car.brand);   // "Tesla"
console.log(car());        // "Vroom! Car is running."
console.log(car.length);   // Built-in property: number of arguments

3. Using a Function as an Object Constructor (2 Marks)

This is how JavaScript implemented Object-Oriented Programming before ES6 classes:

// Constructor Function acts as a class blueprint
function Student(id, name, branch) {
    this.id = id;
    this.name = name;
    this.branch = branch;

    // Method attached to the created object
    this.introduce = function() {
        return "I am " + this.name + " from " + this.branch;
    };
}

// Creating instances of objects using 'new' keyword
var s1 = new Student(1, "Sneha", "E&TC");
var s2 = new Student(2, "Aman", "Electronics");

console.log(s1.introduce()); // "I am Sneha from E&TC"

Q8. Explain how Arrays can be used as Stacks and Queues in JavaScript with suitable examples.
Appeared in: May/Jun 2024, Nov/Dec 2024, May/Jun 2025

1. Overview (1 Mark)

In languages like C, implementing Stacks and Queues requires pointers, linked lists, or fixed arrays. But JavaScript arrays have built-in methods (push, pop, shift, unshift) that let you use an array as both a Stack and a Queue effortlessly.

2. Array as a Stack: LIFO (Last-In, First-Out) (2.5 Marks)

Concept: Just like a stack of dinner plates, the plate placed last on top is the first one picked up.

  • push(item) → Inserts element at the top.
  • pop() → Removes and returns the top element.
var bookStack = [];

// Push operations (Adding to top)
bookStack.push("Maths Book");
bookStack.push("Physics Book");
bookStack.push("JavaScript Book");
console.log("Stack after Pushes:", bookStack); 
// Output: ['Maths Book', 'Physics Book', 'JavaScript Book']

// Pop operation (Removes the latest one added - LIFO)
var removedBook = bookStack.pop();
console.log("Popped Book:", removedBook); // "JavaScript Book"
console.log("Remaining Stack:", bookStack); // ['Maths Book', 'Physics Book']

3. Array as a Queue: FIFO (First-In, First-Out) (2.5 Marks)

Concept: Just like people standing in a line at a ticket counter, the first person to join the queue is the first person served.

  • push(item) → Enqueue (adds new person to the back of the queue).
  • shift() → Dequeue (removes the first person from the front).
var ticketQueue = [];

// Enqueue operations (Adding to the rear/end)
ticketQueue.push("Customer 1 (Alice)");
ticketQueue.push("Customer 2 (Bob)");
ticketQueue.push("Customer 3 (Charlie)");
console.log("Queue:", ticketQueue);

// Dequeue operation (Served from the front - FIFO)
var servedCustomer = ticketQueue.shift();
console.log("Served:", servedCustomer);       // "Customer 1 (Alice)"
console.log("Remaining Queue:", ticketQueue); // ['Customer 2 (Bob)', 'Customer 3 (Charlie)']

Q9. Explain different types of Objects in JavaScript.
Appeared in: May/Jun 2024, Nov/Dec 2024, May/Jun 2025

1. The 3 Main Classes of Objects (1.5 Marks)

In JavaScript, all objects are categorized into 3 broad groups based on where they come from:

  1. User-Defined Objects: Created by you (the programmer).
  2. Built-In / Core Native Objects: Provided standard by JavaScript itself.
  3. Host / Browser Objects (DOM & BOM): Provided by the web browser environment.

2. Detailed Breakdown with Examples (4.5 Marks)

Group 1: User-Defined Objects

Objects that developers define to store specific data. You create them using literals or constructors:

// Created by programmer
var smartphone = {
    brand: "Samsung",
    price: 25000,
    ring: function() { return "Ringing..."; }
};

Group 2: Built-in / Native Objects (ECMAScript Core)

Always available in JavaScript regardless of whether you run it in a browser, in Node.js, or on an embedded system:

  • Math: Mathematical utilities (Math.PI, Math.sqrt).
  • Date: Date and calendar management (new Date()).
  • Array: Ordered lists with indexed keys.
  • String, Number, Boolean: Wrapper objects for primitive types.
  • RegExp: Regular expression pattern matching.

Group 3: Host / Browser Objects

Supplied by the Browser window so JavaScript can interact with HTML and user actions:

  • DOM (Document Object Model): The document object. Lets you read and manipulate HTML elements (e.g., document.getElementById(), document.title).
  • BOM (Browser Object Model):
    • window: The top parent object representing the browser tab.
    • location: Current page URL (e.g., location.href).
    • history: Browser back and forward buttons.
    • navigator: Browser details and device info.

Q10. List various methods of the Math Object. Explain any one with an example.
Appeared in: May/Jun 2024, Nov/Dec 2024, May/Jun 2025

1. Introduction to Math Object (1 Mark)

The Math object is a built-in static object. You cannot do new Math(). All its properties and functions are static and invoked directly as Math.methodName().

2. Table of Popular Math Methods (3 Marks)

Method What it does Example & Result
Math.round(x) Rounds to nearest integer (.5 goes up). Math.round(4.6) → 5
Math.ceil(x) Always rounds UP to the next integer. Math.ceil(4.1) → 5
Math.floor(x) Always rounds DOWN (chops off decimal). Math.floor(4.9) → 4
Math.pow(x, y) Calculates \(x^y\) ($x$ raised to power $y$). Math.pow(2, 3) → 8
Math.sqrt(x) Square root of $x$. Math.sqrt(81) → 9
Math.abs(x) Absolute positive value (strips negative sign). Math.abs(-42) → 42
Math.min(...) Finds lowest value among arguments. Math.min(10, 5, 20) → 5
Math.max(...) Finds highest value among arguments. Math.max(10, 5, 20) → 20
Math.random() Generates random float between $0$ and $1$. Math.random() → 0.4821...

3. Deep-Dive Example: Explaining Math.random() (2 Marks)

Math.random() generates a number from 0 (inclusive) up to 1 (exclusive). In real projects and exams, we use it to generate random whole numbers between any Min and Max (e.g., rolling dice or OTP generation):

// Formula: Math.floor(Math.random() * (max - min + 1)) + min

function getDiceRoll() {
    // Simulates rolling a 6-sided die (Numbers 1 to 6)
    var roll = Math.floor(Math.random() * 6) + 1;
    return roll;
}

function generateOTP() {
    // Generates a 4-digit OTP between 1000 and 9999
    var otp = Math.floor(Math.random() * 9000) + 1000;
    return otp;
}

console.log("Dice Roll:", getDiceRoll()); // e.g., 4
console.log("Generated OTP:", generateOTP()); // e.g., 7349

Q11. Write a JavaScript program to pass a function by reference, perform addition of two objects inside the function, and display the result in the calling function.
Appeared in: Nov/Dec 2022, May/Jun 2023, Nov/Dec 2023

1. Understanding the Question Requirements (2 Marks)

  • Passing Function by Reference: When calling a function, you pass the name of another function without parentheses (e.g., compute(obj1, obj2, addFunc)). You are passing the function like a callback reference.
  • Adding Two Objects: Inside the function, we read properties from both objects (e.g., obj1.marks + obj2.marks), combine them, and return a result object.
  • Displaying in Calling Function: The calling function receives the returned object and prints it.

2. Complete Program (4 Marks)

<!DOCTYPE html>
<html>
<body>
    <h2>Pass Function by Reference Program</h2>
    <div id="resultBox"></div>

    <script>
        // 1. The operation function that will be passed by reference
        function addMarksOfStudents(studentA, studentB) {
            // Performing addition of object properties
            var combinedResult = {
                combinedTheory: studentA.theory + studentB.theory,
                combinedPractical: studentA.practical + studentB.practical,
                totalAggregate: (studentA.theory + studentB.theory) + 
                                (studentA.practical + studentB.practical)
            };
            return combinedResult;
        }

        // 2. Master function that receives a function by reference (callback)
        function executeCalculation(obj1, obj2, operationRef) {
            // Invoking the function via its reference
            var output = operationRef(obj1, obj2);
            return output;
        }

        // --- CALLING FUNCTION / SCRIPT ---
        var s1 = { theory: 65, practical: 22 };
        var s2 = { theory: 70, practical: 24 };

        // Notice: addMarksOfStudents is passed WITHOUT () - this is pass-by-reference!
        var finalScores = executeCalculation(s1, s2, addMarksOfStudents);

        // Displaying the results in the calling scope
        document.getElementById("resultBox").innerHTML = 
            "<p><strong>Combined Theory:</strong> " + finalScores.combinedTheory + "</p>" +
            "<p><strong>Combined Practical:</strong> " + finalScores.combinedPractical + "</p>" +
            "<p><strong>Total Aggregate:</strong> " + finalScores.totalAggregate + "</p>";

        console.log("Final Output:", finalScores);
    </script>
</body>
</html>

Q12. What is a Recursive Function? Explain with an example program.
Appeared in: Nov/Dec 2025, May/Jun 2026
💡 Simple Analogy to Remember: Recursion is like looking between two parallel mirrors where you see reflections inside reflections. You keep stepping inward until you reach the final reflection (Base Case), and then step back out!

1. Definition & Two Must-Have Components (2 Marks)

A Recursive Function is simply a function that calls itself to solve a problem by breaking it into smaller pieces.

Every recursive function must have two mandatory parts:

  1. Base Case (Stopping Condition): The condition that stops recursion. If you forget this, the function will call itself infinitely and crash the browser with a RangeError: Maximum call stack size exceeded!
  2. Recursive Step: The part where the function calls itself with a smaller input (moving closer to the base case).

2. Visual Call Stack for Factorial(3) (1 Mark)

factorial(3) calls 3 * factorial(2)
                       |
               calls 2 * factorial(1)
                             |
                     Base Case Reached! returns 1
                       |
               returns 2 * 1 = 2
        |
returns 3 * 2 = 6 (Final Answer)

3. Standard Exam Program (Factorial & Fibonacci) (3 Marks)

<script>
    // Example 1: Recursive Factorial Calculation (n! = n * (n-1)!)
    function factorial(n) {
        // 1. Base Case: 0! = 1 and 1! = 1
        if (n === 0 || n === 1) {
            return 1;
        }
        // 2. Recursive Step
        return n * factorial(n - 1);
    }

    // Example 2: Recursive Countdown
    function countdown(num) {
        if (num <= 0) {
            console.log("Blastoff!");
            return;
        }
        console.log(num);
        countdown(num - 1); // Calls itself with smaller number
    }

    console.log("Factorial of 5:", factorial(5)); // Output: 120
    countdown(3); // Prints: 3, 2, 1, Blastoff!
</script>

1. The 4 Ways to Create an Object in JavaScript (3 Marks)

Method 1: Object Literal Syntax (Most Popular & Simplest)

var car = {
    brand: "Toyota",
    speed: 120,
    drive: function() { return "Driving..."; }
};

Method 2: Using the new Object() Constructor

var book = new Object();
book.title = "JavaScript Mastery";
book.pages = 350;

Method 3: Using a Constructor Function (For multiple instances)

function Laptop(brand, ram) {
    this.brand = brand;
    this.ram = ram;
}
var myLaptop = new Laptop("HP", "16GB");

Method 4: Using Object.create() (Inheritance from prototype)

var animal = { eats: true };
var dog = Object.create(animal); // dog inherits eats = true
dog.barks = true;

2. How to Access Object Properties (3 Marks)

There are two notations to read or write properties:

Notation Syntax When to use it?
Dot Notation myObject.propertyName Used 90% of the time when the property name is a standard word without spaces.
Bracket Notation myObject["propertyName"] Mandatory if the key has spaces (e.g. "pin code") or is stored in a dynamic variable. 
var profile = {
    username: "ayush_m",
    "full address": "Pune, Maharashtra",
    reputation: 95
};

// 1. Dot Notation:
console.log(profile.username);         // "ayush_m"

// 2. Bracket Notation (for keys with spaces):
console.log(profile["full address"]);   // "Pune, Maharashtra"

// 3. Dynamic Access via variable:
var lookupKey = "reputation";
console.log(profile[lookupKey]);        // 95

Q15. What are the different ways to enumerate properties of an object? Explain with an example.
Appeared in: Nov/Dec 2025

1. The 4 Enumeration Techniques (3 Marks)

"Enumerating" simply means looping through or listing all the properties inside an object. In JavaScript, there are 4 main techniques:

  1. for...in Loop: The classic loop. Iterates over all enumerable keys, including properties inherited from prototypes.
  2. Object.keys(obj): Returns an array of an object's own enumerable property names.
  3. Object.values(obj): Returns an array of an object's own property values.
  4. Object.entries(obj): Returns an array of [key, value] pairs for easy looping.

2. Complete Example Demonstrating All 4 Methods (3 Marks)

<script>
    // Sample Student Object
    var student = {
        name: "Rohan",
        branch: "E&TC",
        year: "Final Year",
        gpa: 8.9
    };

    // Method 1: Traditional for...in Loop
    console.log("--- 1. for...in Loop ---");
    for (var key in student) {
        console.log(key + " = " + student[key]);
    }

    // Method 2: Object.keys() array
    console.log("--- 2. Object.keys() ---");
    var keys = Object.keys(student);
    console.log("All Keys:", keys); // ['name', 'branch', 'year', 'gpa']

    // Method 3: Object.values() array
    console.log("--- 3. Object.values() ---");
    var values = Object.values(student);
    console.log("All Values:", values); // ['Rohan', 'E&TC', 'Final Year', 8.9]

    // Method 4: Object.entries() (Key-Value pairs)
    console.log("--- 4. Object.entries() ---");
    Object.entries(student).forEach(function([k, v]) {
        console.log(k + " : " + v);
    });
</script>
