Q1. Explain Cloud Security Architecture and CIA Security Model (Confidentiality, Integrity, Availability).
Appeared In: May 2023, May 2024, May 2025, May 2026, Nov 2022, Nov 2023, Nov 2024, Nov 2025
Cloud Computing Exam Strategy: Draw neat layered architectural diagrams, clearly differentiate virtualization and platform layers, and state enterprise cloud use cases.

1. CIA Triad in Cloud Computing

  • Confidentiality: Ensuring customer data is inaccessible to unauthorized entities, malicious tenants, or cloud administrators. Enforced via strong symmetric/asymmetric encryption (AES-256, RSA), Key Management Services (KMS), and Identity & Access Management (IAM) role-based permissions.
  • Integrity: Guaranteeing that cloud data and configurations remain accurate, authentic, and unaltered during transit and storage. Achieved through cryptographic hashing (SHA-256), digital signatures, and write-once-read-many (WORM) storage controls.
  • Availability: Ensuring authorized users have uninterrupted, low-latency access to cloud services. Maintained via multi-availability zone redundancy, automated failover, load balancing, and anti-DDoS scrubbing mitigation.

2. Defense-in-Depth Cloud Security Layers

Physical Security $\to$ Network Security (VPC, Firewalls) $\to$ Host Security (Hypervisor Hardening) $\to$ Application Security (WAF) $\to$ Data Security (Encryption at Rest and in Transit).

Q2. Explain Cloud Security Alliance (CSA) Top Threats, Attacks, and Security Issues for Cloud Service Providers.
Appeared In: May 2023, May 2024, May 2025, May 2026, Nov 2022, Nov 2023, Nov 2024
Cloud Computing Exam Strategy: Draw neat layered architectural diagrams, clearly differentiate virtualization and platform layers, and state enterprise cloud use cases.

CSA Top Cloud Threats

  1. Data Breaches & Exfiltration: Sensitive customer databases exposed through misconfigured S3 buckets, compromised IAM credentials, or unencrypted storage volumes.
  2. Weak Identity, Credential, and Access Management: Inadequate Multi-Factor Authentication (MFA), shared root account usage, and hardcoded API keys in client-side code.
  3. Insecure APIs and User Interfaces: Cloud service APIs exposed without rate-limiting or robust authentication, allowing malicious injection attacks and data harvesting.
  4. System & Hypervisor Vulnerabilities (VM Escape): Bugs in hypervisor code allowing an attacker in a guest VM to break out into the host OS, compromising all other co-located tenants.
  5. Account Hijacking: Attackers gaining control of admin accounts via phishing or session token spoofing, gaining full capability to delete cloud instances and backups.
  6. Denial of Service (DoS / DDoS): Volumetric botnet attacks flooding cloud edge endpoints, degrading availability and inflicting massive auto-scaling billing charges (Economic Denial of Sustainability).

Q3. Explain Service-Oriented Architecture (SOA) and Cloud Computing Architecture (COA) / Life Cycle.
Appeared In: May 2023, May 2024, May 2025, Nov 2022, Nov 2023, Nov 2025
Cloud Computing Exam Strategy: Draw neat layered architectural diagrams, clearly differentiate virtualization and platform layers, and state enterprise cloud use cases.

1. Fundamental SOA Components

  • Service Provider: Creates the web service and publishes its interface contract (WSDL / OpenAPI) to a registry.
  • Service Consumer / Requestor: Finds the service contract via discovery registry and binds to it using standard protocols (SOAP, REST, JSON/HTTP).
  • Service Broker / Registry: Central directory (e.g., UDDI) maintaining searchable listings of available services.

2. Cloud Computing Life Cycle Phases

1. Requirement Analysis & Planning $\to$ 2. Cloud Architecture Design (IaaS/PaaS/SaaS selection) $\to$ 3. Deployment & Migration $\to$ 4. Operations, Monitoring & Auto-Scaling $\to$ 5. Governance, Audit & Decommissioning.
