Q1. Explain Enabling Technologies of Internet of Things (IoT): WSN, RFID, Cloud of Things, and Actuators.

Core IoT Enabling Technologies

  1. Wireless Sensor Networks (WSN): Spatially dispersed, autonomous sensor nodes that collaboratively monitor physical conditions (temperature, pressure, vibration). Nodes communicate wirelessly over low-power mesh networks (ZigBee, LoRaWAN, 6LoWPAN) to pass aggregated data to edge gateways.
  2. Radio-Frequency Identification (RFID): Uses electromagnetic fields to automatically identify and track tags attached to objects. Comprises RFID tags (passive/active), reader antenna, and middleware, widely used in supply chain logistics.
  3. Actuators: Electro-mechanical devices that convert control signals into physical motion (e.g., opening valves, turning motors, adjusting thermostats).
  4. Cloud of Things (CoT): Integrating IoT sensor streams with scalable cloud backends, providing centralized big data storage, stream processing (Kafka/Kinesis), and ML analytics.

1. Distributed Computing vs Cloud Computing

ParameterDistributed ComputingCloud Computing
Fundamental ConceptMultiple autonomous computers connected via network sharing data to solve a single common problem.On-demand pool of configurable computing resources delivered as metered utilities over the internet.
Resource AbstractionMachines are visible as separate physical/network nodes to administrators.Resources are completely virtualized and abstracted away from physical hardware.
Service ModelNo standardized billing or service tier models.Delivered via structured service models: IaaS, PaaS, SaaS.
ElasticityFixed cluster size; manual expansion.Highly dynamic auto-scaling (elasticity) based on real-time load.

2. Types of Distributed Systems

  • Distributed Computing Systems: High-Performance Computing (HPC) Clusters and Grids used for parallel scientific calculations.
  • Distributed Information Systems: Transaction processing systems (TP monitors) and Enterprise Application Integration (EAI).
  • Distributed Pervasive Systems: Mobile and embedded ad-hoc sensor networks monitoring real-world environments.

Q3. Explain Innovative Real-World Applications of IoT: Smart Cities, Healthcare, and Smart Agriculture.
Appeared In: May 2023, May 2024, May 2025, Nov 2022, Nov 2023, Nov 2024

Key IoT Enterprise Use Cases

  1. Smart Healthcare (IoMT): Wearable biosensors continuously transmit patient vitals (ECG, pulse oximetry, glucose levels) to cloud EHR systems, enabling automated alerts for arrhythmias and emergency medical intervention.
  2. Smart Cities & Traffic Management: Adaptive traffic light controllers adjust cycle times dynamically based on real-time acoustic/camera sensors, while smart meters monitor municipal water and electricity consumption.
  3. Precision Agriculture: In-ground soil moisture and pH sensors coupled with automated drip-irrigation actuators optimize crop yields while conserving water resources based on real-time weather analytics.
